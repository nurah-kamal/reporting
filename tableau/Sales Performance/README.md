# Sales Performance Dashboard

A Tableau dashboard comparing sales, profit and quantity with the year before. This was a guided project, built by following [this tutorial series](https://www.youtube.com/watch?v=dahrmqT5GD4&list=PLvmB1541_Xx7-2jCqqUzDGea_wwwQesUF&index=3), and it was my practice in year-on-year comparisons in Tableau.

![The Sales Performance dashboard](Dashboard/Sales%20Dashboard.png)

## What it shows

- **Headline figures:** total sales, profit and quantity against the previous year.
- **By month:** sales and profit for the current and previous year, with the best and worst months marked.
- **By subcategory:** sales and profit for each product subcategory.
- **By week:** weekly sales and profit for the current year, with the weeks above and below average marked.
- Filters for product category and subcategory, and a choice of which year to look at.

## Files

- `Sales Performance User Requirements.pdf`: the brief the dashboard was built to.
- `Dashboard/Sales Performance Dashboard.twbx`: the packaged workbook, and `Sales Performance Dashboard_.twb` unpackaged.
- `Dataset/`: orders, customers, products and locations as CSV files.
- `Dashboard Icons/`: the icons used for navigation.
