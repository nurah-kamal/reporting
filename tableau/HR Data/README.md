# HR Dashboard

A Tableau dashboard of a South African workforce, built on synthetic data so that no real employee is in it.

## What it shows

- **Overview:** headcount, and hires over time from each employee's hire date.
- **Demographics:** the workforce by gender, department and education level.
- **Pay:** salary by department, job title, education level and gender.
- **Where people work:** employees by province and city.
- **Employee list:** a filterable table of the generated records.

## The data

The data is generated by a Python script (pandas, numpy and Faker with South African locale settings): 8,950 invented employees across provinces, departments and job titles, with salaries in rands. The script and its documentation are in [Python-For-Data-Analytics](https://github.com/nurah-kamal/Python-For-Data-Analytics/tree/main/South%20African%20HR%20Data%20Set%20Generator).

Because the data is generated, the dashboard shows the patterns the generator was given, not real labour-market findings. It is practice in building and reading an HR dashboard.
