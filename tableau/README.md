# Tableau Projects

Three dashboards I built in Tableau. Each folder has the workbook or a link to it, the data, and a README saying what the dashboard answers.

| Dashboard | Question it answers | Data |
| --- | --- | --- |
| [HR Data](HR%20Data/) | Who works where, how pay compares across departments, roles, education and gender, and how hiring moved over ten years | Synthetic South African workforce data I generated in Python |
| [Data Science Salary Explorer](Data%20Science%20Salary%20Explorer/) | How data science pay varies by role, experience, company size and country | 607 salaries from Kaggle, 2020 to 2022 |
| [Sales Performance](Sales%20Performance/) | How sales and profit compare with last year, by month, week and product subcategory | A retail sample dataset, built as a guided project |

The published versions are on my [Tableau Public profile](https://public.tableau.com/app/profile/nurah.kamal/vizzes).
